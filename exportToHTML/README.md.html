README.md 
1    Учет СКЗИ
2    Автоматизированная система учета средств криптографической защиты информации (СКЗИ) с модулями контроля выдачи, уничтожения, обучения и аудита.
3    
4    🚀 Возможности
5    Регистрация и учёт СКЗИ – привязка к сотрудникам, АРМ, носителям ключевой информации.
6    
7    Ведение справочников – отделы, секторы, сотрудники, наименования СКЗИ, типы носителей, версии ОС, антивирусы, СЗИ от НСД, адреса установки.
8    
9    Отдельные модули – ViPNet Client, СЗИ от НСД.
10   
11   Обучение сотрудников – фиксация результатов проверки знаний.
12   
13   Уничтожение СКЗИ – одиночное и массовое списание с указанием акта.
14   
15   Расширенный фильтр – поиск по нескольким полям и диапазонам дат.
16   
17   Аудит действий – логирование всех изменений (было/стало).
18   
19   Экспорт отчётов – акты установки/уничтожения, ведомость обучения, полный экспорт данных.
20   
21   Импорт справочников – из Excel-файлов.
22   
23   Резервное копирование – с возможностью шифрования паролем.
24   
25   Системный трей – свёртывание в фоновый режим.
26

42   ⚙️ Установка и запуск
43   Клонировать репозиторий:
44   
45   bash
46   git clone https://github.com/ваш-аккаунт/skzi_system.git
47   cd skzi_system
48   Создать виртуальное окружение (рекомендуется):
49   
50   bash
51   python -m venv .venv
52   .venv\Scripts\activate   # Windows
53   Установить зависимости:
54   
55   bash
56   pip install -r requirements.txt
57   Запустить приложение:
58   
59   bash
60   python main.py
61   При первом запуске автоматически создаётся база данных SQLite в папке database/.
62   Учётная запись администратора: admin / admin123.
63   
64   🛠️ Сборка исполняемого файла
65   Используйте PyInstaller:
66   
67   bash
68   pyinstaller --onefile --windowed --icon=resources/app_icon.ico --name="Учет СКЗИ" main.py
69   📁 Структура проекта
70   text
71   skzi_system/
72   ├── db/                 # Модули работы с базой данных (репозитории)

84   ├── requirements.txt    # Зависимости
