Учет СКЗИ
Автоматизированная система учета средств криптографической защиты информации (СКЗИ) с модулями контроля выдачи, уничтожения, обучения и аудита.

🚀 Возможности
Регистрация и учёт СКЗИ – привязка к сотрудникам, АРМ, носителям ключевой информации.

Ведение справочников – отделы, секторы, сотрудники, наименования СКЗИ, типы носителей, версии ОС, антивирусы, СЗИ от НСД, адреса установки.

Отдельные модули – ViPNet Client, СЗИ от НСД.

Обучение сотрудников – фиксация результатов проверки знаний.

Уничтожение СКЗИ – одиночное и массовое списание с указанием акта.

Расширенный фильтр – поиск по нескольким полям и диапазонам дат.

Аудит действий – логирование всех изменений (было/стало).

Экспорт отчётов – акты установки/уничтожения, ведомость обучения, полный экспорт данных.

Импорт справочников – из Excel-файлов.

Резервное копирование – с возможностью шифрования паролем.

Системный трей – свёртывание в фоновый режим.

⚙️ Установка и запуск
Клонировать репозиторий:

bash
git clone https://github.com/ваш-аккаунт/skzi_system.git
cd skzi_system
Создать виртуальное окружение (рекомендуется):

bash
python -m venv .venv
.venv\Scripts\activate   # Windows
Установить зависимости:

bash
pip install -r requirements.txt
Запустить приложение:

bash
python main.py
При первом запуске автоматически создаётся база данных SQLite в папке database/.
Учётная запись администратора: admin / admin123.

🛠️ Сборка исполняемого файла
Используйте PyInstaller:

bash
pyinstaller --onefile --windowed --icon=resources/app_icon.ico --name="Учет СКЗИ" main.py
